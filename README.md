# entreno-legal

Este repositorio contiene dos cosas independientes.

## 1. Documentos legales de Entreno

Política de privacidad pública de la aplicación **Entreno** (entrenamiento HIIT en
casa y registro de gimnasio, Android), publicada con GitHub Pages desde el
`index.html` de la raíz.

- [Política de privacidad / Privacy policy](https://thinkcarchile.github.io/entreno-legal/)

No mover ni reemplazar `index.html`: ese enlace está referenciado desde Google Play.

## 2. HagoTuFila.cl

Plataforma chilena de servicios entre personas: delegar filas, trámites y gestiones
a personas verificadas.

Vive en [`apps/web/`](apps/web) para no interferir con la página anterior. Ver su
[README](apps/web/README.md) para ejecutarla, y `apps/web/docs/` para la arquitectura,
el esquema de base de datos y la hoja de ruta.
